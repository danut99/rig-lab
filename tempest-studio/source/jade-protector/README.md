Jade Protector

Spine 3.8 JSON, atlas and transparent PNG textures. Same 27-bone skeleton and original motion timelines as the shaman. Heavy silver armor, navy clothing and emerald shield. Animations: idle (4s), walk (2.2s), attack (2.1s, shield bash).

The shield uses the existing staff bone, parented to nearHand, with foreground drawing order. The pointed tabard uses a separate body attachment in all three animations. Browser validation checks eight poses in every animation and unchanged bone transforms and motion timelines.
